## 🛒 Modern Full-Stack E-Commerce Platform

A robust, production-ready e-commerce solution built with the latest Next.js 15 features, focusing on performance, scalability, and type safety.

---

## 🌟 Key Features

### 🛒 Customer Experience
- Dynamic Storefront with category-based filtering
- Real-time Smart Search with InstantSearchBar
- Persistent Shopping Cart via CartContextProvider
- Secure Stripe Checkout
- Full Authentication Flow with AuthContextProvider

### 🛠️ Admin Dashboard
- Product CRUD with Vercel Blob image uploads
- Order tracking and status management
- Customer data insights

### 🧪 Testing
- Unit testing with Jest & React Testing Library
- E2E testing with Playwright

---

## 🛠️ Tech Stack

- Framework: Next.js 15.3 (App Router, Turbopack)
- Language: TypeScript
- Database: Firebase Firestore
- Styling: Tailwind CSS v4
- Forms: React Hook Form + Zod
- Payments: Stripe Checkout
- Testing: Jest & Playwright
